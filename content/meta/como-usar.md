# Como usar

- **Editar:** abrir a pasta `arkar-wiki/` como vault no Obsidian. Templates em `_templates/`.
- **Publicar:** so `content/` vai ao site; use os templates e siga a politica de revisao.
- **Nunca** referenciar `interno/` a partir de `content/` (o guard reprova).
- Cada nota entrega valor em 3 blocos: consequencia operacional, erros comuns, relacoes.
