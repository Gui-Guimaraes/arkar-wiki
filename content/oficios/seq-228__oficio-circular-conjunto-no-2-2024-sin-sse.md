# Ofício-Circular Conjunto nº 2/2024/SIN/SSE — N/A

N/A

## Resposta (inteiro teor)

Procedimento operacional temporário para a realização de transformações (Parte Geral) Como ainda estamos em processo de adaptação do sistema, indicamos os seguintes procedimentos: 1. Para os processos em que há o encerramento da(s) classe(s) , como cisão total, incorporação ou fusão, encerrar a(s) classe(s) transformada(s) no sistema SGF. Em caso de encerramento de todas as classes do fundo, este também será encerrado. 2. Para todas as transformações, enviar planilha Excel no formato CSV, conforme modelo anexo. 3. No caso de transferências de classes entre fundos, se a classe transferida for de fundo de classe única, o fundo será cancelado. 4. A planilha com as transformações devem ser enviadas por e-mail, para edyr@cvm.gov.br. 5. Tipo de transformação: 1. Cisão total 2. Cisão parcial 3. Incorporação 4. Transferência Observação: quando uma operação envolver mais de uma classe origem ou destino, incluir uma linha para cada classe envolvida. Exemplos: Cisão parcial da classe A para as classes B, C e D CNPJ classe A | CNPJ classe B | Tipo de transformação 2 | 25/11/2024 CNPJ classe A | CNPJ classe C | Tipo de transformação 2 | 25/11/2024 CNPJ classe A | CNPJ classe D | Tipo de transformação 2 | 25/11/2024
